# Developer Knowledge & Codebase Assistant

A Retrieval-Augmented Generation (RAG) application designed to answer questions about software documentation and source code using retrieved evidence.

## Project Goals

- Understand document ingestion, chunking, and metadata.
- Implement semantic and hybrid retrieval.
- Generate grounded answers with source references.
- Explore advanced RAG techniques and agentic workflows.
- Evaluate retrieval and answer quality.

## Learning Approach

This project is developed incrementally alongside an Advanced RAG course. Each stage introduces concepts, implementation, experiments, and tests.
